# Skill Card — pg-root-cause

| field | value |
|---|---|
| Description | See `SKILL.md` frontmatter. |
| Use case | Turn collected evidence into one of six categories with cited numbers and a ruled-out alternative. |
| Owner | Team GPTOPS (3rd NVIDIA DGX Spark Hackathon) |
| Version | 0.1.0 |
| License | Apache-2.0 |
| Dependencies | Python 3.12 (stdlib only) |
| Data access | None directly; reads the snapshot JSON passed on stdin. |
| Risks | A confident but wrong category can send the operator to the wrong fix. |
| Mitigations | Deterministic rules rank; the answer contract requires cited evidence and a ruled-out alternative; healthy is a valid answer; nothing is executed. |
| Limitations | Covers six categories only (lock contention, idle in transaction, bloat, connection storm, missing index, healthy); thresholds tuned on this lab. |
| Ethical notes | Runs fully on-premises on a DGX Spark; database telemetry is never sent to an external service. Recommendations are advisory; a human owns every tier B/C change. |
| Evaluation | `evals/evals.json` (positive and negative tasks, incl. should-not-trigger cases); results in `BENCHMARK.md`, generated by `python -m evals.run` with and without skills on the same model. |
| Provenance | Business logic ported from the team's KingbaseES diagnosis agent (kb2026: chaos agent, wait-event screening, auto_exec tiers, os_guard). |
